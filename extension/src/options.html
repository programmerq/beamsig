beamsig

Verifies Teleport Beam signatures on GitHub commits in your browser. GitHub reports these as Unverified because it matches SSH signatures only against registered keys and has no notion of an SSH certificate authority — that is GitHub's model, not a defect in the signature.

On by default for every Beams tenant (*.beams.sh), so commits from a tenant you have not seen verify with no setup. A signature's certificate names the cluster it claims to come from; that name is only a claim by whoever signed it, so a fetched CA shows the signer controls a Teleport cluster at that hostname, not that you should trust it. Panels say the CA was discovered. The first CA fetched for a cluster is pinned and never overwritten. One glob pattern per line; empty turns discovery off. See beamsig/discover.py for the full argument.

GitHub API

Unauthenticated requests are limited to 60/hour per IP, which a few commit pages will exhaust. A token raises that to 5,000/hour and is also needed for private repositories. Read-only / public_repo is enough.
The token is stored unencrypted in this extension's local storage, which any code running in the extension can read. Use a scoped, short-lived token, or leave it empty and accept the lower rate limit.

Commit lists

Each row costs one API call, because GitHub's list endpoint carries no signature data. Results are cached permanently (a commit's signature never changes), so revisiting a page is free.
